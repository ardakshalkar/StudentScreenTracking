# Chrome Web Store listing copy · 1.0.1

## Name

Classroom Screen Sharing

## Short description

Share a chosen screen or application window with your classroom teacher. A school-hosted classroom server is required.

## Detailed description

Classroom Screen Sharing connects a student's selected screen or application window to their teacher's classroom dashboard.

IMPORTANT: This is a companion extension. Your teacher or institution must run the Classroom Screen Sharing backend and website and give you its HTTPS server address and classroom joining code. The extension does not include a hosted classroom service. Teachers use the website; students use this extension.

HOW STUDENTS USE IT
• Open the extension controls and enter the server address and classroom code.
• Sign in with an approved Google school account when required by your institution, or enter your classroom name and ID in code-only mode.
• Read the sharing disclosure, acknowledge it, and click Start Sharing.
• Select a screen or application window in Chrome's native permission picker.
• Keep the extension control window open while working in VS Code, Jupyter, PyCharm or another application.
• Stop immediately from the extension controls, toolbar popup or Chrome sharing indicator.

WHAT THE TEACHER CAN DO
• View connected screens, identity, health status and last-image timestamps.
• Open a focused view for more readable code text.
• Optionally enable periodic changed-screenshot recording and review timestamped playback.
• Optionally upload recorded ZIP batches to the teacher's Google Drive account.

CHOICE AND PRIVACY
Capture starts only after your own action and Chrome source selection. No webcam, microphone or audio capture. The extension does not access keystrokes, clipboard contents, browser history or unrelated files through browser APIs. Any private content visible in your selected screen/window can appear in screenshots; close private content before sharing. There is no advertising or analytics tracking in the extension.

Screenshots go to the classroom server you choose, where the authenticated teacher and server operator can access them. Recording is optional, off in a new classroom, and clearly shown in the extension. The default recording interval is one changed screenshot every 20 seconds; default backend screenshot retention is 30 days, configurable by the institution. Uploaded archives may be stored in the teacher's Google Drive. Ask your school about its retention/deletion policy.

REQUIREMENTS
• Current Chrome on Windows, macOS or Linux.
• An active classroom, a trusted HTTPS server address and joining code.
• Google internet access if school sign-in is required.
• On macOS, Chrome may also need Screen Recording permission in system settings.

Window capture availability and updates depend on the OS/compositor. Full-screen sharing is more reliable when a minimized application stops updating. A network outage longer than 30 seconds stops capture and requires you to start sharing again. All teachers should test real capture on their deployment hardware before classroom use.
